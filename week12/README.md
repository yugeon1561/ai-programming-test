12주차 성적 데이터 정제 및 분석

1. 실습 목적

Python과 pandas를 활용하여 성적 데이터의 결측값, 중복, 이상치 및 불필요한 공백을 처리하고 반별·과목별 성적을 분석한다.

8. 결론

전체 평균에서는 1반이 2반보다 6.8점 높았지만, 과목별 평균에서는 모든 과목에서 2반이 높았다. 이는 반마다 과목별 데이터 구성 비율이 다르기 때문이다. 따라서 전체 평균만으로 어느 반의 성적이 더 우수하다고 단정할 수 없으며, 과목별 평균과 데이터 구성 비율을 함께 고려해야 한다.
